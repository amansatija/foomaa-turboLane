## Plan: Endless 3D Traffic Dodger

### Stack
- **Three.js (vendored locally)** — download `three.module.js` once into `lib/` during setup. Game then works fully offline, no npm, no build step.
- **Vanilla ES modules** — serve with `python3 -m http.server` (preinstalled on macOS); README will include the one-liner.

### File structure
```
3dcarracer/
├── index.html          ← canvas, HUD, start menu, game-over screen
├── css/style.css       ← HUD + menu styling
├── lib/three.module.js ← vendored (downloaded once)
├── js/
│   ├── main.js         ← game loop, state machine (menu → playing → game over)
│   ├── car.js          ← player car (built from boxes) + traffic car factory
│   ├── road.js         ← endless scrolling road segments, lane markings, scenery
│   ├── audio.js        ← Web Audio API: engine hum (pitch follows speed) + crash sound
│   └── input.js        ← keyboard (arrows/WASD) + touch swipe for mobile
└── README.md           ← how to run (one command)
```

### Gameplay design
- **Road:** 5-lane straight highway. Road segments + scenery move toward the camera and recycle for cheap endless motion.
- **Player car:** low-poly box-based car with wheels; smooth lane-change steering, accelerate/brake; slight camera tilt on turns.
- **Traffic:** cars spawn ahead in random lanes, slower than player; density ramps with score. AABB collision → game over.
- **Speed & score:** speed auto-rises over time; score = distance + near-miss bonus; best score in localStorage.
- **HUD:** speed (km/h), score, best score.

### Extras (all included)
- Start menu + game-over/restart screens
- Synthesized sounds via Web Audio (engine hum tracking speed, crash thud, near-miss whoosh) — no audio files
- Scenery & polish: gradient sky, fog, shadows, low-poly trees/light poles, dashed lane markings, shoulder stripes
- Minimal structure: short, commented files, no frameworks

### Controls
←/→ or A/D: change lanes · ↑/↓ or W/S: speed / brake · Enter: start/restart · touch swipe on mobile.

### Execution order
1. Download Three.js into `lib/`
2. Scaffold index.html + CSS (HUD, menus)
3. road.js — scrolling road + scenery
4. car.js — player + traffic cars
5. input.js, audio.js
6. main.js — game loop, spawning, collisions, scoring, state machine
7. README + syntax-check all JS files
